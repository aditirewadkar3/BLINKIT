Blinkit Grocery Sales Dashboard – Power BI
📌 Project Overview

This project is an interactive Power BI Dashboard built using the Blinkit Grocery Dataset.
The dashboard provides insights into sales performance, customer preferences, outlet distribution, item categories, and business growth trends.

The main objective of this project is to analyze grocery sales data and transform raw data into meaningful business insights using data visualization and analytics techniques.

🚀 Features
Interactive Power BI dashboard
Sales performance analysis
Item category insights
Outlet establishment trends
Fat content analysis
Outlet size and location analysis
KPI cards for quick business understanding
Dynamic filtering and slicers
📊 Dashboard Insights

The dashboard helps analyze:

Total Sales
Average Sales
Number of Items Sold
Average Rating
Sales by Item Type
Sales by Outlet Size
Sales by Outlet Location
Fat Content Distribution
Outlet Establishment Year Trends
